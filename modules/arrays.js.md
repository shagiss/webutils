# Arrays

## Functions
### unique
**`unique(array)`** - Returns an array with unique values.

Usage:

    import { unique } from "/modules/arrays.js"
    const unique_array = unique(["a","a","a","a","b","b","b","c","c"]); // Will return: ["a","b","c"]

### shuffle
**`shuffle(array)`** - Returns a shuffled array.

Usage:

    import { shuffle } from "/modules/arrays.js"
    const shuffled_array = shuffle(["a","b","c"]);
