# Strings
## Functions
### charset
**`charset(start, end)`** - Generate list of characters

Usage:
```javascript
import { charset } from "/modules/strings.js"
console.log( charset("a","z") ) // will return the a-z
```

### capitalize
**`capitalize(string)`** - Converts the first letter of a string to an uppercase (e.g. from 'john' to 'John')

Usage:
```javascript
import { capitalize } from "/modules/strings.js"
console.log( capitalize("john") )
```
